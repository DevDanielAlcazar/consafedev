# ConSafeDev — Design Token Contract V1

## Color system

The logo remains the source of brand identity. Current prototype values are derived from the supplied raster identity and may be refined when final SVG assets are delivered.

| Token | Value | Purpose |
|---|---|---|
| `--cs-engineering-950` | `#081C24` | Immersive Engineering Space |
| `--cs-navy-800` | `#03324C` | Primary brand navy |
| `--cs-teal-500` | `#05B19B` | Active / connected / actionable |
| `--cs-mint-200` | `#A8EDE3` | Rare high-energy highlight |
| `--cs-paper-50` | `#F4F7F5` | Clarity Space |
| `--cs-surface-0` | `#FFFFFF` | Elevated clear surface |
| `--cs-ink-900` | `#10252C` | Primary text on light |
| `--cs-steel-600` | `#596F74` | Secondary text |
| `--cs-mist-200` | `#DCE7E4` | Dividers / subtle surfaces |

### Semantic rule

**Teal means active, connected, functioning or actionable.**

Do not use teal simply to decorate large areas.

## Typography

### Display
Preferred: `Instrument Sans`.

### Body
Preferred: `Inter`.

### Data / system
Preferred: `JetBrains Mono`.

Mono is for labels, statuses, IDs and system-detail moments only.

If adding a font creates unnecessary prototype complexity, preserve the hierarchy and document the temporary substitution. Do not silently substitute final typography.

## Fluid type

Use `clamp()` based scales.

Guideline:
- Hero: ~72–88px desktop.
- Display 2: ~56–64px.
- H2: ~42–52px.
- H3: ~28–34px.
- Lead: ~20–22px.
- Body: ~16–18px.
- UI: ~14–16px.
- Meta: ~12–13px.

Long-form copy target: ~55–70 characters per line.

## Grid

Desktop:
- 12-column composition.
- Maximum stage width: 1440px.
- Frequent editorial width: 1200–1280px.
- Responsive gutters.

Required design states:
- mobile;
- tablet;
- compact desktop;
- desktop;
- wide.

## Spacing

Base unit: 4px.
Primary rhythm: `8 / 12 / 16 / 24 / 32 / 48 / 64 / 96 / 128`.

## Radius

- button: 10–12px;
- small UI: 8–10px;
- panel: 14–18px;
- media: 20–24px only when appropriate.

Pills are for tags/statuses, not every control.

## Shadows

Minimal. Prefer tonal separation, line work, layering and controlled luminance.

## ConSafe Frame

A subtle geometric signature derived from the shield:
- occasional 45° cut;
- interrupted border;
- continuing line;
- offset corner.

Use sparingly.

## Imagery

Primary visual material:
- system diagrams;
- interface fragments;
- architecture relationships;
- operational states;
- product behavior.

Stock photography is not part of the primary Build 01 language.
