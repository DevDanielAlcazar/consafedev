# ConSafeDev — Experience Contract V1

Este paquete es el contrato operativo para agentes de implementación durante la reconstrucción de la landing de ConSafeDev.

## Principio de gobierno

La IA es **implementador**, no product owner, estratega de marca, arquitecto UX ni director creativo.

Cuando exista conflicto entre una especificación aprobada y la conveniencia de implementación del agente, prevalece la especificación. El agente debe reportar la restricción y pedir una decisión humana si no puede cumplirla sin degradar la experiencia.
